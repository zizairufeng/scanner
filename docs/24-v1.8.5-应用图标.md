# v1.8.5 — 应用图标

## 一句话

之前这个 App **根本没有图标**：`AndroidManifest.xml` 的 `<application>` 上连
`android:icon` 都没写，`res/` 下也没有任何 mipmap —— 装到手机上显示的是系统默认图标，
不同 ROM 长得还不一样（有的是灰色小机器人，有的是绿色方块）。
这一版补上一套完整的 adaptive icon：深绿渐变底 + 白色四角取景框 + 亮绿条码。

## 设计取舍

为什么是取景框 + 条码

- 取景框是扫码类工具的通用视觉语言，用户看一眼就知道"这是个扫描的 App"；
- 但**没画成完整方框**——完整框缩到 48dp 会糊成一块空心方块，且看起来像"图片占位符"。
  改成四角各留一个开口（臂长 19 / 48），小尺寸下四个角仍然分得清，也不会和背景糊在一起。
- 条码用宽窄交替的 4 根（6 / 4 / 5.5 / 6），而不是等宽竖线：真条码就是宽窄不等的，
  这个节奏让它一眼是"条码"而不是"栅栏"。
- 没选 DataMatrix 点阵（虽然这是本 App 的特色能力，能扫金属蚀刻方码）：5×5 点阵缩到
  48dp 会糊成一片麻点，而普通条码是大众认知。

**配色**

| 用途 | 色值 | 理由 |
|---|---|---|
| 背景左上 | `#1E9E74` | 与 App 内 `HintSuccess` 同一个绿系 |
| 背景右下 | `#041A16` | 压到近黑，白框才立得住 |
| 左上柔光 | `#78F0C3` 34%→9%→0 | 让渐变不是死板的线性，有一点光源感 |
| 取景框 | `#FFFFFF` | 纯白，小尺寸下最不容易糊 |
| 条码 | `#7BE8B0` | 亮绿，和背景同色系但拉开明度 |

深色底的好处：在浅色桌面、深色桌面、彩色壁纸上都立得住（三种桌面都合成验证过）。

```
             宽度 6 / 4 / 5.5 / 6，合计 30.5，左右各留 6 白边，中心正好 54
```

## 三层资源

Adaptive icon 在 API 26 之后是三层叠出来的，缺一层就会退回不理想的兜底：

| 资源 | 路径 | 作用 |
|---|---|---|
| 背景层 | `drawable/ic_launcher_background.xml` | 线性渐变 + 径向柔光，两层 vector |
| 前景层 | `drawable/ic_launcher_foreground.xml` | 取景框（stroke）+ 条码（fill） |
| 单色层 | `drawable/ic_launcher_monochrome.xml` | Android 13 主题图标用，系统自动染色 |

- `mipmap-anydpi-v26/` 放 `adaptive-icon`（不含 monochrome，旧系统不认这个属性）；
- `mipmap-anydpi-v33/` 放带 `<monochrome>` 的版本；
- `mipmap-{m,h,x,xx,xxx}dpi/ic_launcher.png` + `ic_launcher_round.png`：
  API 24/25 没有 adaptive icon，必须给位图。方形带 20% 圆角，圆形做 alpha 遮罩。

## 两个容易踩的坑

**1. 渐变方向不能用 `android:angle`**

`<shape>` 的 `android:angle` 在不同系统版本上解释不一致（同一份 XML 可能一个版本是
左上→右下、另一个版本反过来）。所以背景层用 `vector` + `aapt:attr` 的 `gradient`，
把方向钉死成 `startX=0,startY=0 → endX=108,endY=108`（就是左上 → 右下），
新旧图标不会出现"一个亮在上、一个亮在下"。

2. 位图和矢量必须同一套参数

老系统看 PNG、新系统看矢量。如果两边分别手工调，就会出现"同一台手机换台看图标不一样"。
所以全部由 `tools/gen_icon.py` 从一个参数表生成：`_gradient` 用 numpy 算出的像素
和矢量层的「线性 gradient + 径向 gradient」是逐像素等价的（同样的 stop、同样的中心与半径）。

改图标 = 改脚本顶部参数后重跑，不要手改生成的 XML。

## 生成与验收

```bash
python3 tools/gen_icon.py --preview /tmp/icon.png
```

产出 10 个 PNG + 7 个 XML。验收项：

- 244/244 单测通过（图标不涉及逻辑，无新增用例）；
- `aapt2 dump badging` 的 `application-icon-*` 各密度都有值，`application: label` 正常；
- 权限仍然只有 `CAMERA` + `VIBRATE`（加图标不该动权限，这是回归基线）；
- 与上一版 APK 的体积差应小于 100 KB（图标资源总量很小）。

**未真机实测**（构建环境无 adb 设备）：需要确认桌面图标观感、圆形遮罩下四角是否被切、
Android 13 主题图标（取色后）是否还认得出。
