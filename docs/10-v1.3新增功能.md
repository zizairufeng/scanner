## 一、F2 · 计数聚合（去重开关升级为三态）

原来的「去重 开 / 关」两个状态，改成三个互斥口径，主屏预览下方的 chip 点一下循环切换：

| 口径 | chip 显示 | 行为 | 适合场景 |
|---|---|---|---|
| **严格去重**（默认） | `严格去重` | 列表里已有的码不再计入，无论隔多久 | 资产盘点、序列号采集 |
| **计数聚合** | `计数聚合` | 重复扫到同一码 → 该行数量 **+1**，仍只占一行（显示 `×N`） | 箱数清点、同款商品计数 |
| **允许重复** | `允许重复` | 同一码离开画面满时间窗后可再次录入，每次占新行 | 需要逐次留痕的特殊口径 |

关键：时间窗防刷屏在三种口径下都生效。切换口径绝不是「不限速逐帧留痕」的开关——
持续对准一个码，任何一种口径都不会一秒记十几条。需要重新录入时把码移开画面，
等时间窗（默认 1500ms）过去再扫。

数量列的影响：

- 复制 / 导出的 CSV 与 xlsx 多了一列 `数量`
- 纯文本与「序号+Tab」格式在计数聚合下按数量**展开成多行**（下游贴进表格时行数才对得上）
- 删掉某一行后重扫该码：会重新作为新行计入（删除时同步清掉了时间戳与聚合记录）

## 二、F4 · 会话防丢（本地持久化）

结果列表不再只活在内存里。每次变动后延时 500ms 合并写盘（原子写：临时文件 + rename）。

- 冷启动时若发现上次未收尾的会话，主屏顶部出现一张**恢复卡片**，显示条数与保存时间，
  「恢复 / 丢弃」你自己选。**不自动恢复**——口径可能已经换了，自动灌进来反而更烦
- 主动「清空」会同时删除快照；导出不删
- 设置面板里有总开关 **「记住本次会话」**，关掉后不再写盘，下次启动也不提示恢复
- 存储位置：App 私有 `filesDir/session.tsv`，不申请任何权限、不联网、不进相册
- 文件格式是自制 TSV（不是 JSON）：`org.json` 在纯 JVM 单测里会 "not mocked"，
  用自制格式才能把这块逻辑纳入单测（见 `SessionStoreTest`）
- 坏文件（格式不认识、字段解析失败）会被**自动删除**，不会每次启动都卡在同一处

## 三、F6 · 条码规则过滤

设置面板里新增，白名单性质，三条规则是「与」关系，任何一条留空就跳过该条：

| 规则 | 说明 |
|---|---|
| 前缀 | 必须以此前缀开头（如只收 `69` 开头的 EAN-13） |
| 长度 | 必须恰好是这个长度（0 = 不限） |
| 正则 | 必须匹配该正则（空 = 不限） |

- 默认关闭；开启后不符合的码**直接不计入**，连震动和提示音都不会有
- **非法正则不会崩溃**：会被当作「该条不限制」处理，并在设置面板给出错误提示
- 三条全空时设置面板会提示「还没填内容」，避免开了开关却什么都没拦

## 四、F1 · 自动变焦

启用 ML Kit 17.3.0 已有的 `ZoomSuggestionOptions`：码太小 / 太远时回调建议倍率，
自动调 `cameraControl.setZoomRatio`。

- 设置面板有开关，默认**开启**
- 建议倍率会先与 `maxSupportedZoomRatio` 取小，不会超限报错
- 与手动双击缩放共存：手动调过之后，下一次自动建议仍会生效（后到的为准）
- 零体积代价（用的是已集成的 ML Kit 能力），但真机效果无法验证——
  它是 native 行为，取决于机型模组，装上去试一下就知道

## 五、F3 + F11 · 导出与分享

复制按钮旁边新增**导出**入口，三种格式任选，导出后直接拉起系统分享面板
（微信 / QQ / 邮件 / 网盘 / 蓝牙都能收）：

| 格式 | 说明 |
|---|---|
| 纯文本 `.txt` | 一行一个码 |
| CSV `.csv` | 带表头（序号 / 码制 / 内容 / 时间 / 数量），Excel 可直接打开 |
| **Excel `.xlsx`** | 真 xlsx 文件，序号与数量是**数值型**（打开即可求和，不用再转换） |

- 走 `FileProvider` + `ACTION_SEND`，零权限、零联网，只授权这一次分享的单个 Uri
- 文件名带时间戳：`ScanStock_20260918_015600.xlsx`
- xlsx 是手写 zip + XML 生成的（约 200 行，无第三方依赖），已在单测里校验 zip 结构、
  必要条目（`[Content_Types].xml`、`xl/worksheets/sheet1.xml`）与控制字符处理
- 导出目录是 `cacheDir/exports`，每次导出前清掉上一次的产物

## 六、F9 · 撤销删除

删除单条后，底部提示条上出现**「撤销」**，5 秒内可恢复该条（连原来的序号一起恢复）。
超时、或又做了别的操作，提示条消失后不可再撤销。「清空全部」不提供撤销——
那是明确的整体操作，误触代价太高不适合给一键撤销。
